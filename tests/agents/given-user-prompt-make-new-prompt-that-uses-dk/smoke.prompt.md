# Smoke prompts

Canonical sample user requests for the two-stage eval. Each corresponds to a
`<short id>/prompt.txt` sample in the private prompt-studio plan. The first is the
seed already used on the site.

## seed-video (clear)

I want software that screen captures a window (Excel, web browser, etc.) and
records me dictating a video speech for my team. After recording, the ums and ahs
and silence should automatically be edited out. The captured window should be
displayed in the bottom left or bottom right, avoiding my face as much as possible.
All of the video should have a copyright notice on the bottom in small print.

## photo-organizer (clear)

I have thousands of photos in one big folder and I want a program that sorts them
into albums by the date they were taken and by who is in them, so I can find family
pictures fast.

## csv-search (clear)

I have hundreds of CSV files from different months and I want them merged into one
searchable database, with duplicates removed, and a simple window where I can type
a search and see matching rows.

## watch-folder (clear)

I want a tool that watches a folder on my PC, and whenever I drop in a new photo it
automatically shrinks the file size and stamps my logo in the corner, then saves it
to an "uploads" folder.

## business-app (unclear)

an app for my business

## recipe (not software)

what is a good recipe for dinner tonight
